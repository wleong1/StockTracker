This site contains the project documentation for the
'Calculators' project that is used mainly for individual
tax calculation purposes. Its aim is to provide users
with a fairly accurate amount of tax paid, given the
financial year and calculator.

## Project Overview

StockTracker is a Python application that helps analyse and visualise stock performance data for S&P 500 companies. It provides a user-friendly GUI for comparing stock prices, viewing historical trends, and staying updated with the latest news.
